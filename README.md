# 🏏 IPL Historical Performance Dashboard

A comprehensive Excel-based interactive dashboard analyzing Indian Premier League (IPL) match data, team performance metrics, toss decisions, venue statistics, and individual player achievements.

---

## 📌 Project Overview

This dashboard aggregates multi-season IPL match datasets to extract actionable insights into match dynamics, team success strategies, and key player performances. It models key performance indicators (KPIs), tournament finals history, and match conditions into an intuitive, visual analytical interface.

---

## 📊 Key Features & Analysis

- **Team Performance & Win Metrics:** Detailed breakdown of total matches won by each franchise across seasons.
- **Toss Decision & Match Impact Analysis:** Evaluation of how toss wins correlate with match outcomes (choosing to bat vs. field first).
- **Venue Analytics:** Distribution of matches and win rates across key stadiums and grounds.
- **Player Achievements (MOM):** Identification of top Man of the Match award winners and individual impact players.
- **Finals & Champions Tracking:** Analysis of IPL title winners, runners-up, and championship match statistics.
- **Interactive Pivot Tables & Visualizations:** Structured dynamic pivot summaries enable drill-down filtering by season, team, and venue.

---

## 📂 Data Model & Excel Workbook Structure

The workbook (`IPL Dashboard.xlsx`) is structured into dedicated analytical components:

| Sheet Name | Description |
| :--- | :--- |
| **`IPL Dashboard`** | Main visual layout containing KPIs, charts, slicers, and summary metrics. |
| **`KPI`** | Core key performance indicator calculations and overall tournament statistics. |
| **`Matches win by team`** | Aggregated match outcomes grouped by franchise. |
| **`Toss Win`** | Analysis of toss decisions (Bat vs. Field) and win ratios. |
| **`Venue`** | Stadium-level match counts and outcome distributions. |
| **`MOM`** | Man of the Match awards leaderboard. |
| **`Winners`** | Historical listing of season title champions. |
| **`Finals_Data`** | Detailed performance statistics from championship finals. |
| **`IPL Info`** | Raw match data and metadata powering the backend calculations. |
